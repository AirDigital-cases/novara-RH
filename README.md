# Novare RH

Base inicial do MVP de um sistema SaaS de RH com backend Flask e frontend React/Vite/Tailwind.

## Estrutura

- `backend/`: API modular com autenticacao JWT, empresas, vagas, candidatos, testes e dashboard.
- `frontend/`: interface inicial com layout premium, responsivo e preparada para integrar com a API.

## Proximo passo sugerido

1. Criar e ativar um ambiente virtual no `backend/`.
2. Instalar dependencias com `pip install -r backend/requirements.txt`.
3. Instalar dependencias do frontend com `npm install` dentro de `frontend/`.
4. Subir a API com `python backend/wsgi.py`.
5. Subir o frontend com `npm run dev` dentro de `frontend/`.
